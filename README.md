# Prep Simulator for TOEFL

A free Android app by [HomiLabs](https://homilabs.org) for the TOEFL iBT in its current (January 2026) format:
20 full-length mock tests with adaptive Reading and Listening, Writing and Speaking tasks, estimated 1-6 band scores
with CEFR level and comparable 0-120 total, every answer explained, lessons and practice for all 13 task types,
model answers, guidance, tips and study plans, and vocabulary flashcards. Independent practice material; TOEFL® is a
registered trademark of ETS, which does not endorse this app.

- App: Flutter, in `lib/`. Project notes: `CLAUDE.md`.
- Content: `content/`, built into `assets/data/` by `tool/build_content.py`.
- Website: `website/`, live at https://tofel.homilabs.org.
- Release and hosting: `docs/release-and-hosting.md`.
